# 🏧 ATM Simulator — C++

A simple console-based ATM Simulator developed in C++ as one of my early programming projects.

This project was created to practice programming fundamentals by building a small ATM-like system from scratch.

## ✨ Features

- 🔐 Account number and PIN authentication
- 👤 Multiple predefined user accounts
- 💰 Check account balance
- 💸 Withdraw money
- 💵 Deposit money
- 🔑 PIN verification for transactions
- ⚠️ Basic input validation
- 🔄 Continue/logout options
- 🚫 Login attempt limitation

## 🛠️ Technologies Used

- C++
- Standard C++ libraries
- Console / Terminal

## 📌 How It Works

The program contains three predefined accounts, each with its own account number, PIN, and balance.

After entering a valid account number and PIN, the user can:

1. Check their balance
2. Withdraw money
3. Deposit money
4. Return to the main window
5. Exit the application

The program also performs basic checks such as account validation, PIN verification, insufficient balance handling, and invalid menu input.

## 🎯 Purpose of the Project

The main purpose of this project was to understand and practice:

- Variables and data types
- Arrays
- Loops
- Conditional statements
- `switch` statements
- Character arrays and strings
- Functions from the C++ standard library
- Input validation
- Basic program flow and logic

Rather than using a database or external system, the account information is stored directly in the program. This keeps the project simple and focused on learning C++ fundamentals.
